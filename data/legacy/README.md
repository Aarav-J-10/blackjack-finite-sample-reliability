# Legacy source data

These files are preserved solely for provenance and auditability. They were
generated by the earlier blackjack implementation and must not be presented as
outputs of the corrected six-deck simulator.

The audit identified two linked defects:

1. the nominal six-deck shoe contained 78 cards rather than 312; and
2. the cut-card threshold was also 78, causing a reshuffle before each round.

The specific evidence is recorded in
`../../results/tables/legacy_source_audit.csv`. The corrected analysis is in
`../../scripts/run_pfme_analysis.py`.

Files in this directory include the originally supplied workbook, derived CSV
summaries, round- and hand-level data, experiment settings, and the exported
legacy notebook code used by the audit.
