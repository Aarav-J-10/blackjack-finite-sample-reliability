# Results

The archived results were produced by the corrected simulator with the full
configuration (`R=10,000` for the main sample-size grid).

- `tables/blackjack_pfme_results.csv`: principal paired and unpaired blackjack
  estimates.
- `tables/blackjack_replication_pairs.csv`: replication-level matched returns.
- `tables/required_sample_sizes.csv`: blackjack normal-planning sample sizes.
- `tables/cross_domain_pfme_results.csv`: blackjack, inventory, and queue results.
- `tables/cross_domain_required_sample_sizes.csv`: cross-domain planning table.
- `tables/blackjack_rule_sensitivity.csv`: rule-condition sensitivity.
- `tables/blackjack_strategy_comparison.csv`: seven-strategy comparison.
- `tables/bootstrap_ci_comparison.csv`: bootstrap and normal interval comparison.
- `tables/validation_tests.csv`: simulator checks.
- `tables/legacy_source_audit.csv`: documented legacy defects.
- `tables/inventory_exact_risk.csv`: exact analytical inventory benchmark.
- `tables/bernoulli_exact_risk.csv`: strict, tie, and nonpositive Bernoulli risk.
- `workbook/PFME_results.xlsx`: formatted workbook of the primary results.

The archived full-run metadata are in `run_metadata.json`.
